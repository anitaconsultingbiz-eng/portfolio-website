# Anita Perez Work Examples

This is a single-page work portfolio designed to support the separate Anita Perez consulting website.

## Files

- index.html — page content and representative work samples
- styles.css — layout, colors, responsive design, and work-sample styling
- favicon.svg — browser-tab icon

Keep all three files in the same folder.

## Preview in Visual Studio Code

1. Open this folder in Visual Studio Code.
2. Open index.html.
3. Use the Live Server extension or open index.html directly in a browser.

## Publish with GitHub Pages

Place the three files at the root of the portfolio repository, commit the changes, and push them to GitHub. In the repository settings, confirm that GitHub Pages deploys from the main branch and the root folder.
